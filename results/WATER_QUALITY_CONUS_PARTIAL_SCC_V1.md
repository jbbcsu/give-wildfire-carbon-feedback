# Freshwater-quality recreational welfare: bounded CONUS benchmark

## Result

Using five official EPA FrEDI v4.1.1 climate-model response surfaces, the mean bounded partial SCC is **$0.01668 per metric tonne CO2** in 2020 USD under GIVE's 2% Ramsey discounting. The across-GCM range is **$0.01283-$0.02184/tCO2**, and the median is **$0.01649/tCO2**.

This estimate covers 2025-2092, the common interval over which both matched GIVE baseline/pulse temperatures remain within the 0-3 C CONUS-anomaly support shared by all five water-quality surfaces. It uses a 2025 pulse of 0.0001 GtC (366,666.67 metric tonnes CO2).

## Interpretation

The result values climate-driven degradation of freshwater recreation opportunities through transferred user and nonuser willingness to pay. The underlying chain includes modeled freshwater temperature, dissolved oxygen, nitrogen, and phosphorus summarized in a water-quality index. It is a welfare endpoint rather than lost agricultural output or commercial forestry revenue.

The small value should not be interpreted as the total ecosystem or biodiversity SCC. It omits terrestrial biodiversity loss, pollination, forestry, habitat, carbon-storage feedbacks, health effects, municipal treatment/scarcity costs, property amenities, most cultural services, and all impacts outside CONUS. Truncation after 2092 omits later damages because the GISS-E2-R response surface ends at 3 C.

## Release status

This is an independently reconciled, reproducible **bounded regional benchmark**. It is not authorized for global extrapolation or addition to the combined GIVE SCC. Freshwater fishing use value and water-quality nonuse value must first be reconciled with future freshwater-fisheries and biodiversity-nonuse modules.
