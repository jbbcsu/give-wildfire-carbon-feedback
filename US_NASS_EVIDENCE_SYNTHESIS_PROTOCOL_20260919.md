does not refit a response, create an untouched holdout, or select by damage
magnitude. Read only the independently checked aggregate common-rainfall-range,
paired predictive-loss, Tmax-control sensitivity, and post-result 2020--2025
all-practice PDSI comparison artifacts; bind each and the latter's independent
validation by SHA-256. Read no county yield rows, coefficients, predictions,
or raw weather.

Report the primary common-range quantity associations for corn/soy and reported
irrigated/non-irrigated practice. A response is consistently negative across
weather sources only if both source point estimates and both upper interval
endpoints are below zero. State whether each irrigated interval includes zero;
do not interpret practice differences as treatment effects.

For non-irrigated crops, report pooled conditional county-bootstrap RMSE
differences for distribution and seasonal PDSI relative to quantity under the
baseline controls. Then report the preregistered state/materiality selection
status under baseline and added stage-Tmax controls, plus the sign count of
state-specific PDSI advantages and terminal-test sign. Negative paired loss
differences favor the candidate; positive summary improvements favor the
candidate. Preserve these distinct sign conventions explicitly.

not causal, nationally production weighted, a global transfer parameter,
climate-change attribution, adaptation estimate, damage function, or SCC
input. Distribution remains primary only if its frozen state/materiality gate
survives both temperature-control designs; otherwise it remains a sensitivity.

common and state-specific trends and state the lowest model without treating a
